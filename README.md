# Маршрут курьера

Страница, которая из маршрутного листа 1С (.xlsx) делает ссылки на маршруты в Яндекс Картах.

Что делает:

1. Читает лист: название точки, адрес, количество мест, тип оплаты, номер реализации. Несколько накладных на один адрес — одна остановка.
2. Находит координаты адресов: через Яндекс Геокодер, если в настройках указан ключ, иначе через OpenStreetMap.
3. Считает порядок объезда с наименьшим пробегом. Старт — склад (по умолчанию «Самара, Садовая 292»), последняя точка выбирается сама, либо задаётся в настройках.
4. Делит цепочку на несколько ссылок: в одном маршруте Яндекс Карт не больше 10 точек, поэтому каждая следующая ссылка начинается с последнего адреса предыдущей.

## Установка

1. Загрузить в репозиторий три файла: `index.html`, `xlsx.full.min.js`, `README.md`.
2. Settings → Pages → Deploy from a branch → `main` / `(root)`.
3. Открыть `https://<аккаунт>.github.io/<репозиторий>/`.

## Ключ Яндекса (необязательно, но адреса находятся точнее)

1. Войти на https://developer.tech.yandex.ru/ под аккаунтом Яндекса.
2. «Подключить API» → «JavaScript API и HTTP Геокодер», заполнить анкету.
3. Скопировать ключ и вставить на странице в «Настройки маршрута».

Ключ хранится только в браузере, в репозиторий не попадает. Если в кабинете у ключа включено ограничение по HTTP Referer, добавьте туда адрес страницы на github.io.

## Если точка встала не туда

У каждого адреса есть ссылка «на карте» и кнопка «поправить точку»: вставляете координаты из Яндекс Карт (правый клик по дому → «Что здесь?»). Исправление запоминается в браузере и на следующих листах подставляется само.

## Что уходит наружу

Сам файл никуда не загружается. Адреса отправляются геокодеру (Яндекс или OpenStreetMap), координаты — в открытый сервис OSRM для расчёта расстояний по дорогам. Если OSRM не ответил, порядок считается по прямым расстояниям.
