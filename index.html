Маршрут курьера

Загрузите маршрутный лист из 1С — получите ссылки на Яндекс Карты с адресами в порядке кратчайшего объезда.

Выбрать маршрутный лист (.xlsx) или перетащите файл сюда
Настройки маршрута

С ключом координаты адресов ищет Яндекс — так точнее. Без ключа — OpenStreetMap. Ключ бесплатный: developer.tech.yandex.ru → «Подключить API» → «JavaScript API и HTTP Геокодер». Хранится только в этом браузере.

Координаты адресов запоминаются в этом браузере, поэтому знакомые точки на следующий день определяются мгновенно. Сам файл никуда не загружается: наружу уходят только адреса (в Яндекс или OpenStreetMap, чтобы найти координаты) и координаты (в сервис OSRM, чтобы посчитать расстояния по дорогам).
